# Yashwanth Ganji — Engineering Portfolio

A static portfolio site built with HTML, CSS, and JavaScript. It highlights projects in embedded systems, software, and robotics, along with experience and a printable resume.

## Run locally

```sh
npm install
npm run start
```

## Publish with GitHub Pages

This project uses Vite. For GitHub Pages, configure the repository's Pages workflow to build with `npm run build` and publish the generated `dist/` directory. Project-page links and asset paths are relative so the site can be hosted beneath the repository path.
